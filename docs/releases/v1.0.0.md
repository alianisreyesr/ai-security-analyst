# AI Security Analyst v1.0.0

The first stable portfolio release delivers an explainable workflow to ingest
telemetry, normalize events, detect suspicious behavior, score risk, preserve
evidence, and investigate findings in a responsive dashboard.

## Highlights

- Deterministic authentication, port-scan, and request-rate detections.
- Explainable risk scoring with stored evidence and MITRE ATT&CK context.
- Optional validated AI summaries that never determine severity.
- PostgreSQL persistence, analytics, correlation, and analyst reviews.
- Accessible React/TypeScript dashboard and synthetic guided demo.
- Hardened configuration and automated quality/security gates.

The release workflow validates metadata, enforces 85% backend coverage, builds
the frontend, rejects tracked secret filenames, and attaches a source archive
with its SHA-256 checksum.
